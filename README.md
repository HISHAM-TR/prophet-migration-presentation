# رحلة الهجرة النبوية الشريفة - عرض تقديمي تفاعلي متكامل (HTML, CSS, JavaScript)

عرض تقديمي احترافي وتفاعلي مصمم بأحدث معايير الويب (HTML5, CSS3, Vanilla JavaScript) بدون أي مكتبات خارجية معقدة، يروي قصة ومسار رحلة الهجرة النبوية المباركة من مكة المكرمة إلى المدينة المنورة بأسلوب تاريخي موثق وتصميم إسلامي فاخر وعصري.

---

## 🌟 مميزات العرض التقديمي

1. **تصميم إسلامي راقٍ وأنيق**:
   - لوحة ألوان مستوحاة من الليالي النبوية والذهب العربي والأخضر الزمردي الهادئ (`Dark Emerald`, `Imperial Gold`, `Desert Sand`).
   - زخارف هندسية إسلامية خلفية رقيقة بتأثير الزجاج المصقول (Glassmorphism).
   - خطوط عربية أصيلة وعالية الوضوح (Amiri للآيات والأحاديث، Cairo للعناوين، وTajawal للنصوص).

2. **عشر شرائح متكاملة تغطي أدق تفاصيل الهجرة**:
   - **الشريحة 1**: شريحة الغلاف والمقدمة العامة وإحصائيات الرحلة.
   - **الشريحة 2**: إرهاصات الهجرة وأسبابها (اشتداد الأذى، بيعتا العقبة، ومؤامرة دار الندوة).
   - **الشريحة 3**: عبقرية التخطيط والأخذ بالأسباب وتوزيع الأدوار (أبو بكر، علي، أسماء، عبد الله بن أبي بكر، عامر بن فهيرة، وابن أريقط).
   - **الشريحة 4**: الانطلاق المعجز والمكوث ثلاث ليالٍ في غار ثور (معجزة السكينة واليقين).
   - **الشريحة 5**: المسار الاستثنائي الوعر (طريق الساحل لتضليل عيون قريش وجائزة الـ 100 ناقة).
   - **الشريحة 6**: مطاردة سراقة بن مالك ومعجزة غوص قوائم الفرس وبشارة سواري كسرى.
   - **الشريحة 7**: خيمة أم معبد الخزاعية (معجزة الشاة ودرّ اللبن، وأدق وصف خَلقي وخُلقي للنبي ﷺ).
   - **الشريحة 8**: الوصول الميمون إلى قباء وتأسيس أول مسجد في الإسلام ولحاق علي بن أبي طالب.
   - **الشريحة 9**: الدخول المشهود إلى يثرب (المدينة المنورة)، استقبال الأنصار، إنشاد «طلع البدر علينا»، وبروك الناقة القصواء.
   - **الشريحة 10**: الدروس والعبر المستفادة والتأثير الحضاري الخالد وتأسيس التقويم الهجري.

3. **خريطة تفاعلية لمسار الهجرة (Interactive Route Map)**:
   - رسم بياني متقن بالـ SVG يوضح مسار الهجرة الفعلي مقارنة بطريق القوافل المعتاد.
   - نقاط تفاعلية للمحطات (مكة، غار ثور، الساحل، خيمة أم معبد، سراقة، قباء، يثرب).
   - إمكانية القفز المباشر للشريحة المتعلقة بأي محطة بمجرد النقر عليها.

4. **أدوات الملقي والعارض الذكية**:
   - **مؤقت عرض زمني حي**: يبدأ العد تلقائياً لمساعدة الملقي في إدارة وقت كلمته.
   - **ملاحظات الملقي (Speaker Notes)**: لكل شريحة نقاط إرشادية وتاريخية تساعد المحاضر على الشرح والتعليق.
   - **فهرس الشرائح وشبكة التصفح (Grid View)**: معاينة سريعة لجميع الشرائح والانتقال المباشر.
   - **مؤثرات صوتية هادئة**: نغمة انتقال رقيقة باستخدام (Web Audio API) تعمل محلياً دون الحاجة لملفات صوت خارجية، مع خيار كتمها.
   - **دعم كامل لملء الشاشة والطباعة**: تشغيل العرض بملء الشاشة، وإمكانية طباعة الشرائح أو حفظها كملف PDF نظيف.

## ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
| :--- | :--- |
| **السهم الأيسر (←)** أو **مسافة** أو **Page Down** | الانتقال للشريحة التالية |
| **السهم الأيمن (→)** أو **Page Up** | الرجوع للشريحة السابقة |
| **Home** | الانتقال للشريحة الأولى مباشرة |
| **End** | الانتقال للشريحة الأخيرة |
| **F** | تبديل وضع ملء الشاشة (Fullscreen) |
| **M** | فتح / إغلاق خريطة المسار التفاعلية |
| **G** | فتح / إغلاق فهرس الشرائح (Grid Overview) |
| **N** | فتح / إغلاق ملاحظات الملقي (Speaker Notes) |
| **Escape** | إغلاق أي نافذة منبثقة مفتوحة |
